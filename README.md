# الكاتب السريع

مسابقة طباعة سريعة على لوحة المفاتيح، تعمل من رابط واحد على عدة حاسبات في الوقت نفسه.

الجهة المنظمة: قسم إدارة الأعمال، شعبة النشاطات الطلابية — كلية الإدارة والاقتصاد، جامعة الموصل
برمجة وتصميم: علي عبد الوهاب الصفار

## طريقة العمل

1. يفتح كل متسابق الرابط ويسجل اسمه وقسمه (يُحفظ الاسم للجولات التالية).
2. الحكم يكتب جملة موحدة للجولة ويشغّل العداد التنازلي.
3. يُحسب وقت كل متسابق حتى يكتب الجملة صحيحة كاملة.
4. تنتهي الجولة بانتهاء آخر متسابق، ويحدد الحكم عدد المستبعدين.
5. في النهاية تظهر قائمة نهائية بكل المتسابقين وأوقاتهم.

رمز لوحة الحكم موجود في `index.html` في المتغير `ADMIN_PIN`.

## ربط قاعدة البيانات (مرة واحدة)

1. ادخل إلى https://console.firebase.google.com وأنشئ مشروعاً جديداً.
2. من القائمة: Build > Firestore Database > Create database (اختر أقرب منطقة).
3. من تبويب Rules الصق محتوى الملف `firestore.rules` ثم Publish.
4. من Project settings > Your apps اضغط أيقونة الويب `</>` وسجّل تطبيقاً.
5. انسخ قيم `firebaseConfig` إلى الملف `config.js`.

## الملفات

- `index.html` — التطبيق كاملاً.
- `config.js` — إعدادات Firebase.
- `firestore.rules` — قواعد حماية قاعدة البيانات.
